# Roblox Slap Guessing Game

This project contains scripts for a Roblox game where players can slap each other and guess who slapped whom. The game includes a slap button system, slap detection, and a guessing system.

## Install

1. Place the `SlapButtonScript.server.lua` script in the `ServerScriptService` folder.
2. Place the `SlapDetectionScript.server.lua` script in the `ServerScriptService` folder.
3. Place the `GuessingSystemScript.server.lua` script in the `ServerScriptService` folder.

## Use

1. Players will see a button to slap other players.
2. When a player is slapped, the slap action is detected and logged.
3. Players can submit guesses about who slapped whom, which are also logged.
